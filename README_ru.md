# tabby-clipsnag

[English](README.md) | Русский

Плагин для терминала [Tabby](https://tabby.sh). Нажмите горячую клавишу, дайте
«шумной» команде отработать, нажмите её снова — плагин вырежет ANSI-мусор управления и
положит в буфер обмена чистый текст.

Это как «выделить весь вывод последней команды», но работающее по реальному потоку
байтов (цвета, перемещение курсора, перерисовки TUI и всё остальное), а не по скроллбеку
терминала. Работает одинаково независимо от того, уехал вывод за пределы экрана или нет.

## Возможности

- **Одна горячая клавиша-переключатель** (по умолчанию `Ctrl-Shift-X`, `⌘-Shift-X` на
  macOS) для запуска и остановки.
- **Пассивный захват** — устанавливает `SessionMiddleware`, который наблюдает байты и
  передаёт их дальше без изменений; при записи терминал отображается точно как раньше.
- **Корректное удаление ANSI** — весь захват декодируется и очищается один раз при
  остановке, поэтому цветовые коды, движение курсора, OSC-заголовки и гиперссылки никогда
  не попадут в буфер обмена.
- **Ограниченная память** — захват перестаёт расти при достижимом лимите (по умолчанию
  **5 МБ**), сохраняются самые ранние байты, а факт усечения сообщается в уведомлении.
- **Авто-остановка по простою** — опционально останавливается сам после N секунд тишины
  (по умолчанию 3 с).
- **UI настроек** — все параметры редактируются в **Settings → Clipsnag**; править вручную
  ничего не нужно.
- **Безопасно относительно утечек** — всё уничтожается вместе с вкладкой; закрытие
  записываемой вкладки чисто отменяет запись без «висячих» подписок.

## Настройка

Всё редактируется в **Settings → Clipsnag** (а горячая клавиша — в
**Settings → Hotkeys → Toggle terminal output snagging**). Те же значения хранятся под
ключом `clipsnag` в `~/.config/tabby/config.yaml` (`%APPDATA%\tabby\config.yaml` на Windows)
и могут быть отредактированы вручную там же, хотя UI настроек — рекомендуемый способ:

```yaml
hotkeys:
  clipsnag-toggle: Ctrl-Shift-X

clipsnag:
  maxCaptureBytes: 5242880        # жёсткий лимит 5 МБ; старые байты сохраняются, остальное отбрасывается
  autoStopAfterIdleMs: 3000       # остановка после 3с тишины; 0 отключает авто-остановку
  copyToClipboardOnStop: true     # записывать очищенный текст в буфер обмена ОС
  stopOnTabSwitch: false          # остановка и копирование при переключении на другую вкладку
```

## Как это работает

```
hotkey ──▶ ClipsnagService.toggle()
              │
              ├─ start: resolve active terminal tab
              │          └─ TerminalDecorator.startRecording(tab, sink)
              │                └─ CaptureMiddleware pushed into session.middleware
              │                     └─ feedFromSession() copies bytes into CaptureBuffer
              │
              └─ stop:  CaptureBuffer.finish()
                           ├─ Buffer.concat + utf8 decode
                           ├─ stripAnsi(...)
                           └─ PlatformService.setClipboard({ text })
```

- `TerminalDecorator` предоставляет хук жизненного цикла на вкладку и гарантирует очистку
  через `subscribeUntilDestroyed`.
- `SessionMiddleware` — единственный поддерживаемый способ увидеть сырой поток байтов
  сессии.
- Сервис владеет единственной активной записью и подписывается на горячую клавишу один раз.

Так как байты накапливаются (а не декодируются по чанкам), многобайтовые символы UTF-8,
разделённые между чанками PTY, остаются целыми, а ANSI-последовательности, пересекающие
границы чанков, удаляются корректно.

## Сборка

Требуется Node 18+.

```bash
npm install
npm run build      # -> dist/index.js (+ .d.ts)
npm run watch      # инкрементальная пересборка во время разработки
npm run typecheck  # tsc --noEmit
npm run lint       # eslint
```

## Установка в Tabby для тестирования

Выберите удобный вариант:

### Вариант A — указать Tabby на папку (быстрее всего для разработки)

```bash
# Linux / macOS
tabby --plugin-dir=/absolute/path/to/tabby-clipsnag

# Windows (PowerShell)
tabby --plugin-dir=C:\Users\you\github\alexoffspace\tabby-clipsnag
```

`--plugin-dir` должен указывать на корень проекта (папку с `package.json` и `dist/`).
Сначала запустите `npm run build`.

### Вариант B — положить в каталог плагинов

Скопируйте `package.json` и всю папку `dist/` в пользовательский каталог плагинов:

```
Linux:   ~/.config/tabby/plugins/node_modules/tabby-clipsnag/
macOS:   ~/Library/Application Support/tabby/plugins/node_modules/tabby-clipsnag/
Windows: %APPDATA%\tabby\plugins\node_modules\tabby-clipsnag\
```

Затем перезапустите Tabby.

### Проверка загрузки

Откройте **Settings → Plugins** — там должен быть указан `tabby-clipsnag`. Затем:

1. Сфокусируйте вкладку терминала и запустите `ls --color=always`.
2. Нажмите `Ctrl-Shift-X` — появится уведомление *recording …*.
3. Нажмите `Ctrl-Shift-X` снова — второе уведомление сообщит размер; вставьте куда угодно.

Первое нажатие взводит захват, второе — останавливает его. При `autoStopAfterIdleMs > 0`
можно также просто подождать: запись завершится автоматически, когда вывод затихнет.
